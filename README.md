# ☕ Cafe Sales Performance & Data Reliability Analysis

## 📌 Overview
This project analyzes a cafe sales dataset to uncover insights and validate revenue accuracy.

## 🎯 Business Problem
The business lacked clarity on revenue drivers, product performance, and data reliability.

## 🧹 Data Cleaning
- Removed blank rows
- Standardized "UNKNOWN" and "ERROR"
- Converted data types
- Handled missing values
- Validated revenue calculations

## 📊 Analysis
- Revenue by item
- Revenue by location
- Payment method distribution
- Monthly trends

## 📈 Dashboard
Interactive dashboard created using Excel Pivot Tables, charts, and slicers.

## 💡 Key Insights
- Top-performing products identified
- Best-performing locations highlighted
- No revenue discrepancies found
- Missing data identified as key limitation

## 🛠 Tools Used
- Excel
- Power Query
